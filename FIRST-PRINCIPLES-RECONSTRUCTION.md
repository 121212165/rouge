# First-Principles Reconstruction: rouge

> Applied Elon Musk's first-principles thinking: break to fundamental truths, rebuild from zero.

## Core Problem

A quick roguelike dungeon crawler with meaningful tactical decisions.

## First Principles Breakdown

1. A roguelike is a decision engine. Every encounter should present a meaningful choice.
2. Stats are inputs to a damage formula. More stats != more fun.
3. Replayability comes from decision variety.

## Reconstruction Blueprint

~800 lines (from ~2,137, 62% reduction) with zero loss in core gameplay value.

## Musk\'s Razor

Every system that adds code without adding decisions gets cut.
